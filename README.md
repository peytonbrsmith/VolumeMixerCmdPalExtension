# Overview

Volume Mixer adds a dedicated volume mixer to [Microsoft PowerToys Command Palette](https://learn.microsoft.com/windows/powertoys/command-palette/overview).

Use it to access volume controls quickly from Command Palette without navigating through Windows system settings. The extension also provides a dock band for persistent, quick-access controls.

## Features

- Open the Volume Mixer directly from Command Palette.
- Access the extension from the Command Palette dock.
- Use the extension settings page to configure supported options.
- Runs out-of-process as a packaged Command Palette extension.
- Supports x64 and ARM64 builds.

## Requirements

- Windows 10 version 19041 or later.
- [Microsoft PowerToys](https://github.com/microsoft/PowerToys) with Command Palette enabled.
- For building:
  - Visual Studio 2026 or later.
  - The **.NET desktop development** workload.
  - The .NET 10 SDK.
  - Windows 10/11 SDK version 26100 or later.
- A supported processor architecture:
  - x64
  - ARM64

# Installation

## Install from a self-built package

This project uses the standard Visual Studio MSIX deployment workflow.

1. Clone the repository:

   ```powershell
   git clone https://github.com/peytonbrsmith/VolumeMixerExtension.git
   cd VolumeMixerExtension
   ```

2. Open `VolumeMixerExtension.sln` in Visual Studio.

3. Select a supported configuration:
   - `Debug` or `Release`
   - `x64` or `ARM64`

4. Deploy the project by selecting **Build > Deploy**.

   > Use **Deploy**, not only **Build**. Deployment registers the MSIX package and the Command Palette extension with Windows.

5. If Windows prompts you to trust the development certificate, accept the prompt so the package can be installed.

6. Open Command Palette and run:

   ```text
   Reload
   ```

7. Select **Reload Command Palette extensions**.

8. Search for **Volume Mixer**.

## Installing a package manually

A package generated by Visual Studio can typically be found under the project's build output directory, such as:

```text
VolumeMixerExtension\bin\x64\Debug\
```

or:

```text
VolumeMixerExtension\bin\ARM64\Debug\
```

The exact package location depends on the selected configuration and Visual Studio MSIX tooling version.

Open the generated `.msix` or `.msixbundle` file to install it. If the package includes an `.appinstaller` file, open that file instead.

After installation, reload Command Palette:

1. Open Command Palette.
2. Run `Reload`.
3. Select **Reload Command Palette extensions**.
4. Search for **Volume Mixer**.

> Manual installation may require trusting the development certificate used to sign the package.

# Build from the command line

Restore the solution:

```powershell
dotnet restore .\VolumeMixerExtension.sln
```

Build the x64 Release configuration:

```powershell
dotnet build .\VolumeMixerExtension\VolumeMixerExtension.csproj `
  --configuration Release `
  --runtime win-x64 `
  --property:Platform=x64
```

Build the ARM64 Release configuration:

```powershell
dotnet build .\VolumeMixerExtension\VolumeMixerExtension.csproj `
  --configuration Release `
  --runtime win-arm64 `
  --property:Platform=ARM64
```

The project targets:

```text
net10.0-windows10.0.26100.0
```

A command-line build validates the project but does not necessarily register the extension with Command Palette. Use Visual Studio **Build > Deploy**, or install the generated MSIX package manually, to register the extension.

# Debugging

To debug the extension:

1. Open `VolumeMixerExtension.sln` in Visual Studio.
2. Select the `Debug` configuration.
3. Select the appropriate platform.
4. Start debugging with **Debug > Start Debugging** or press `F5`.
5. Check the Visual Studio Output window if the extension does not start.
6. After deployment, run `Reload` in Command Palette.

The project includes packaged and unpackaged launch profiles:

- `VolumeMixerExtension (Package)` — runs through the MSIX package.
- `VolumeMixerExtension (Unpackaged)` — runs the project directly.

# Architecture

Volume Mixer is implemented as an out-of-process Command Palette extension.

- `Program.cs` hosts the COM server.
- `VolumeMixerExtension` exposes the Command Palette extension entry point.
- `VolumeMixerExtensionCommandsProvider` registers the top-level command and dock band.
- The extension pages provide the mixer and dock user interfaces.
- `Package.appxmanifest` registers the COM server and Command Palette app extension.
- `Assets/VolumeMixerIcon.png` provides the extension icon.
